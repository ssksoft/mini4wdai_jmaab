# 再現検証チェックシート（Python制御シミュレーター）

`docs/manual.md` **だけを見て**、シミュレーションを再現できるかを確かめるためのシートです。

- 所要時間：1〜2 時間
- 作成者に聞かずに進めてください。詰まった場所・迷った場所そのものが、マニュアルを直すための情報になります。
- 各項目について、「結果」の欄に OK / NG を、「メモ」の欄に気づいたことを書いてください。表示された文字・数値・エラーは、そのまま貼り付けてください。
